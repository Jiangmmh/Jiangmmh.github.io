LKD阅读笔记-第三章

一、进程是什么？ 进程（Process）是程序执行过程中的一个实例。 程序（Program）是存储在磁盘上的静态指令和数据，而进程是程序运行时的动态实体。一个程序可以对应多个进程；一个进程也不只是代码本身，它还拥有自己的运行状态、虚拟地址空间、打开的文件、信号处理信息以及处理器上下文等资源。 从操作系统的角度看，进程是资源分配和管理的重要单位，也是内核进行调度和管理的基本对象。 一个进程通常包含以下几个方面： 代码和数据：程序的指令以及全局变量、静态变量等。 虚拟地址空间：进程可以访问的虚拟内存范围。 打开的文件：进程持有的文件描述符及其对应的内核对象。 处理器上下文：程序计数器、寄存器、栈指针等运行状态。 进程控制信息：进程 ID、父进程、状态、调度信息等。 需要注意：进程是内核管理的实体，而不是简单的一段代码。 二、进程描述符与 task_struct 2.1 什么是进程描述符？ 内核需要一种数据结构来描述和管理进程。 Linux 使用 struct task_struct 表示进程描述符（Process Descriptor）。它定义在： include/linux/sched.h 每一个进程都有一个对应的 task_struct，内核通过它获取进程的状态、调度信息、内存管理信息以及其他资源。 可以把 task_struct 理解为内核管理进程的核心控制块，类似于其他操作系统中的 PCB（Process Control Block）。 Linux 的进程描述符包含大量信息，常见字段如下： 字段 作用 state 进程当前状态 pid 进程 ID tgid 线程组 ID flags 进程标志 prio 动态优先级 static_prio 静态优先级 normal_prio 普通优先级 policy 调度策略 mm 进程内存描述符 active_mm 当前活动地址空间 parent 父进程 children 子进程链表 real_parent 实际父进程 files 打开的文件信息 fs 文件系统相关信息 signal 信号相关信息 sighand 信号处理信息 tasks 进程任务链表节点 注意：这里列出的是帮助理解的代表性字段，不意味着不同 Linux 内核版本中的字段布局完全一致。Linux 内核数据结构会随着版本不断演进。 ...
