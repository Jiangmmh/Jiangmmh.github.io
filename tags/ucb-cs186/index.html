UCB CS186 Project 1：SQL

一、项目介绍 UCB CS186: Introduction to Database Systems 是加州大学伯克利分校开设的数据库系统课程。课程通过理论讲解与编程项目相结合的方式，帮助学生理解数据库系统的设计与实现。 Project 1 主要围绕 SQL 展开，通过查询真实数据集，练习关系型数据库中最常用的查询操作。 本项目使用 Lahman Baseball Database，包含了大量美国职业棒球运动员的个人信息、比赛记录、球队信息、薪资以及名人堂入选记录等数据。 项目主要涉及以下 SQL 知识： 基础查询：SELECT、WHERE、ORDER BY； 聚合查询：GROUP BY、HAVING、COUNT、SUM、AVG； 多表查询：INNER JOIN、LEFT JOIN； 子查询与公共表表达式：WITH、CTE； 窗口函数：LAG()； 条件表达式：CASE WHEN； 数据分桶与统计分析。 虽然这些内容都是 SQL 的基础知识，但通过本项目，可以进一步理解如何将实际业务需求转换为关系代数和 SQL 查询。 1.1 环境准备 首先拉取项目仓库： git clone https://github.com/berkeley-cs186/sp26-proj1.git cd sp26-proj1 下载数据库文件：lahman.db 将数据库文件放到项目要求的位置。 本项目使用 SQLite，因此可以直接使用 SQLite 命令行工具查看数据库。 sqlite3 lahman.db 查看数据库中的表： .tables 查看表结构： .schema people .schema batting .schema salaries 也可以直接查询部分数据： SELECT * FROM people LIMIT 10; 建议在正式开始之前，先了解数据表的结构以及表之间的关联关系。对于数据库查询任务而言，理解数据模型往往比直接编写 SQL 更重要。 ...
