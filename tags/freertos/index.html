FreeRTOS book 第一章：简介

一、FreeRTOS 是什么？ 1.1 FreeRTOS 的基本介绍 FreeRTOS 是一套面向嵌入式系统的开源软件，主要由实时内核（Real-Time Kernel）以及一系列提供辅助功能的模块化软件库组成。 它最初由 Richard Barry 于 2003 年左右开发，后来由 Amazon Web Services（AWS）接手维护。FreeRTOS 使用 MIT 开源许可证，既可以用于个人项目，也可以用于商业产品。 FreeRTOS 的主要目标是为微控制器（MCU）和小型微处理器提供实时多任务处理能力。 在没有 RTOS 的传统裸机程序中，应用程序通常由一个主循环控制： int main(void) { hardware_init(); while (1) { read_sensor(); process_data(); update_display(); handle_communication(); } } 这种方式也被称为 Super Loop（超级循环）或前后台系统。 当应用程序比较简单时，这种结构完全可行。但是，随着功能不断增加，系统可能同时需要： 周期性采集传感器数据。 实时响应外部事件。 更新显示界面。 处理通信协议。 执行控制算法。 管理设备状态。 如果所有功能都放在一个循环中，就需要开发者自行管理每个功能的执行时机、执行顺序以及等待时间。 例如，通信处理过程中如果需要等待数据，可能会影响传感器采集；如果某个功能执行时间过长，也可能导致其他功能错过执行时机。 FreeRTOS 通过引入任务（Task）和调度器（Scheduler），将应用程序组织成多个相对独立的执行单元，并由内核决定哪个任务获得 CPU 执行权。 可以将其理解为： Application | +-------------+-------------+ | | | Sensor Task Control Task Communication Task | | | +-------------+-------------+ | FreeRTOS Kernel | Hardware 每个任务负责一项相对独立的工作，任务之间通过内核提供的通信和同步机制协作。 ...
