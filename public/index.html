一生一芯-F3阶段笔记

处理器芯片本质上是数字电路。数字电路是用来处理数字信号的电路, 而数字信号简单来说是指0和1这两种离散的信号. 这里的0和1并不是数学意义上的自然数, 它是指信号的两种不同状态, 为了简单叙述, 就分别称它们为0和1. 为了和数学上的0和1区分开来, 有时候也将上面两种状态称为逻辑0和逻辑1。 因此, 处理器芯片本质上也是处理0和1这两种信号的芯片. 要学习处理器芯片设计, 数字电路的知识是基础. 而要学习数字电路, 就是需要学习信息在数字电路中是如何表示, 处理和存储的。具体地, 你将会了解: 如何表示 - 数字信号0和1在数字电路中的物理含义 如何处理 - 门电路和组合逻辑电路的工作原理 如何存储 - 时序逻辑电路的工作原理 课程笔记 1. 如何表示0和1？ 关键问题：数字电路如何表示0和1（物理含义），以及如何处理它们？ 数字电路用物理量的两个离散区间表示 0 和 1：最常见的是低电平=0、高电平=1，并用阈值区间和噪声容限保证在真实电路中可靠区分，而不是依赖精确的单一电压值。 使用晶体管处理数字信号：一个晶体管包含三个极（Source、Drain和Gate），其作用类似于一个开关，通过在Gate端加入不同电压可以控制Source和Drain的导通与断开。 2. CMOS 在实际的硬件设计中，通常使用一个nMOS和一个pMOS构造CMOS来实现0和1。 下面这个CMOS本身其实是一个反相器，即输入A为0，输出Y为1；输入A为1，输出Y为0。 关键问题：一个晶体管就能作为开关，为什么要用两个晶体管构成CMOS？ 单看逻辑功能，一个 nMOS 确实就能当开关用——栅极给高电平导通、给低电平截止。那为什么几乎所有的现代数字电路都用 CMOS（互补金属氧化物半导体，即 nMOS + pMOS 配对）而不是单管方案？ nMOS擅长传递低电平，pMOS擅长传递高电平，反过来会导致信号衰减。 CMOS的静态功耗低。 CMOS的互补结构使高低电平的噪声容限对称、较大。 CMOS 工艺中 NMOS 和 PMOS 可以成对制造，版图规整、易于自动布局布线，也便于用标准单元库大规模综合。单管方案往往需要电阻、特殊器件，难以标准化和缩放。 虽然一个晶体管也能"通断"，但只有 nMOS + pMOS 互补配对，才能同时做到：完整传递 0 和 1、主动驱动、静态几乎不耗电、电平可恢复、易于大规模集成。 CMOS 不是"两个管子干一个管子的活"的浪费，而是用互补换来了功耗、电平、可靠性、可扩展性的全面胜利。 3. 使用CMOS构建逻辑门电路 与非门： ...
