Leetcode 链表专题

这篇笔记整理了 51 道链表相关题目，使用 C++ 实现。它既是刷题记录，也是一份按问题模式组织的复习手册：重点不在记住某一道题的代码，而在识别题目背后的链表操作模式，并能解释指针变化、边界条件和复杂度。 链表题的主要难点通常不是算法本身，而是节点关系的维护。写代码前，建议先明确：要改变哪条 next 链接、是否需要前驱节点、操作后链表是否仍然连通、是否会形成环，以及是否需要保留原链表。 阅读与练习建议 第一次学习：先读题意和思路，遮住代码，自己画出 3～5 个节点的指针变化。 第二次复习：只看每题的核心模式，尝试从空链表、单节点、头尾节点等边界重新写一遍。 第三次复习：重点比较相似题，例如“删除重复元素 I / II”“反转链表 / 反转区间 / K 组反转”“LRU / LFU / AllOne”。 代码中的 ListNode、Node 通常由 LeetCode 提供定义；不同题目中的节点类型并不通用。 题单来源 题目链接见灵神的题单：链表题单。 链表操作的基本约定 本文多数代码采用 LeetCode 常见的裸指针接口。dummy（哨兵节点）通常是栈上对象，只负责简化头节点操作，不应被 delete；通过 new 创建并最终成为返回链表一部分的节点，则由题目平台或调用方按题目约定管理。若把代码移植到独立 C++ 项目，应进一步明确节点所有权，优先考虑 unique_ptr、容器或明确的析构策略。 一、遍历链表 1. 二进制链表转整数 链表元素均为0或1，整个链表表示一个二进制数（最高位在链表头部），将该链表转换为该二进制数的十进制值。 思路：将ans初始化为0，遍历该链表，每遇到一个节点就将ans左移一位并加上当前节点的值。 时间复杂度为：O(n)，n为链表长度 class Solution { public: int getDecimalValue(ListNode* head) { int ans = 0; for (auto cur = head; cur; cur = cur->next) { ans = (ans << 1) + cur->val; } return ans; } }; 2. 找出临界点之间的最小和最大距离 临界点就是极值点（严格大于或小于两侧元素）。 ...
