在F阶段我们了解了数字电路的原理（数字信号的表示、存储和处理）和状态机模型，使用Ligisim实现了一个简单的sCPU，并在其上运行了数列求和程序。但是，Logisim的方案难以满足现代处理器设计的需求，因此在E1阶段中我将学习使用HDL（硬件描述语言）实现处理器。 我的学习路线是：先过了一遍verilog的基本语法，然后刷HDLBits中的题目。 verilog语法简介：https://vlab.ustc.edu.cn/guide/doc_verilog.html HDLBits 网址：https://hdlbits.01xz.net/wiki/Main_Page HDLBits提供了大量的Verilog的练习题，由浅入深，非常适合verilog的初学者。 这篇文章的内容主要是我刷HDLBits题目的笔记，请根据需要阅读。 这两天基本上把HDLBits中的题目全部刷了一遍，大部份题目已经吃透，少部份未能完全理解，后续有时间再复习吧。 Getting Started Step one Hardware Description Language（硬件描述语言）使用代码来描述数字硬件。 下面是一个最简单的示例： module top_module( output one ); assign one = 1; endmodule 该代码定义了一个名为top_module的module，没有输入，只有一个输出名为one，其中使用assign语句将输出端one置为1。 Zero 同上，不过这里将输出端置为0。 module top_module( output zero );// Module body starts after semicolon assign zero = 0; endmodule Verilog Language Basics Wire Create a module with one input and one output that behaves like a wire. 和物理的连线（wire）不同，verilog中的连线是有方向的。 我们可以使用assign语句连接输入和输出。 module top_module( input in, output out ); assign out = in; endmodule Wire4 Create a module with 3 inputs and 4 outputs that behaves like wires that makes these connections: ...
