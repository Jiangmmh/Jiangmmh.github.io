Leetecode 链表

这篇文章记录了链表相关的重点算法题 （共51道），使用C++实现。 题目链接见灵神的题单：链表题单。 一、遍历链表 1. 二进制链表转整数 链表元素均为0或1，整个链表表示一个二进制数（最高位在链表头部），将该链表转换为该二进制数的十进制值。 思路：将ans初始化为0，遍历该链表，每遇到一个节点就将ans左移一位并加上当前节点的值。 时间复杂度为：O(n)，n为链表长度 class Solution { public: int getDecimalValue(ListNode* head) { int ans = 0; for (auto cur = head; cur; cur = cur->next) { ans = (ans << 1) + cur->val; } return ans; } }; 2. 找出临界点之间的最小和最大距 临界点就是极值点（严格大于或小于两侧元素）。 我的思路：先遍历链表，找出全部的临界点，再遍历找出的临界点数组，得到最大和最小临界点距离。 编写函数findLocalMinMax，找出全部临界点，并返回临界点的下标数组localMinMax 最大临界点距离就是localMinMax第一个元素与最后一个元素之差 最小临界点距离就是localMinMax中相邻元素之差的最小值 时间复杂度：O(n), n为输入链表的长度 空间复杂度：O(n) class Solution { vector<int> findLocalMinMax(ListNode *head) { vector<int> ans; if (!head || !head->next) return ans; auto prev = head; int idx = 1; for (auto cur = head->next; cur->next; cur = cur->next) { // 取出前驱和后继的值 int p = prev->val, q = cur->next->val; int x = cur->val; if ((p < x && q < x) || (p > x && q > x)) { ans.push_back(idx); } prev = cur; idx++; } return ans; } public: vector<int> nodesBetweenCriticalPoints(ListNode* head) { // 找到全部的临界点 vector<int> localMinMax = findLocalMinMax(head); int n = localMinMax.size(); // 临界点数量少于两个，直接返回 {-1, -1} if (n < 2) return {-1, -1}; int maxDistance = localMinMax[n-1] - localMinMax[0]; int minDistance = INT_MAX; for (int i = 1; i < n; i++) { minDistance = min(minDistance, localMinMax[i] - localMinMax[i-1]); } return {minDistance, maxDistance}; } }; 优化：可以在遍历链表的过程中，记录第一个临界点的位置和记录前一个临界点的位置，来得到最大和最小临界点距离，将空间复杂度降为O(1)。 ...
