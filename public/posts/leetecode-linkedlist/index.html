一、遍历链表#

1. 二进制链表转整数#

链表元素均为0或1，整个链表表示一个二进制数（最高位在链表头部），将该链表转换为该二进制数的十进制值。

思路：将ans初始化为0，遍历该链表，每遇到一个节点就将ans左移一位并加上当前节点的值。

时间复杂度为：O(n)，n为链表长度


class Solution {

public:

    int getDecimalValue(ListNode* head) {

        int ans = 0;

        for (auto cur = head; cur; cur = cur->next) {

            ans = (ans << 1) + cur->val;

        }


        return ans;

    }

};

2. 找出临界点之间的最小和最大距离#

临界点就是极值点（严格大于或小于两侧元素）。

我的思路：先遍历链表，找出全部的临界点，再遍历找出的临界点数组，得到最大和最小临界点距离。

  • 编写函数findLocalMinMax，找出全部临界点，并返回临界点的下标数组localMinMax

  • 最大临界点距离就是localMinMax第一个元素与最后一个元素之差

  • 最小临界点距离就是localMinMax中相邻元素之差的最小值

时间复杂度：O(n)，n 为输入链表的长度

空间复杂度：O(n)


class Solution {

    vector<int> findLocalMinMax(ListNode *head) {

        vector<int> ans;

        if (!head || !head->next) return ans;

        auto prev = head;

        int idx = 1;

        for (auto cur = head->next; cur->next; cur = cur->next) {

            // 取出前驱和后继的值

            int p = prev->val, q = cur->next->val;

            int x = cur->val;


            if ((p < x && q < x) || (p > x && q > x)) {

                ans.push_back(idx);

            }


            prev = cur;

            idx++;

        }


        return ans;

    }

public:

    vector<int> nodesBetweenCriticalPoints(ListNode* head) {

        // 找到全部的临界点

        vector<int> localMinMax = findLocalMinMax(head);

        int n = localMinMax.size();

        // 临界点数量少于两个，直接返回 {-1, -1}

        if (n < 2) return {-1, -1};


        int maxDistance = localMinMax[n-1] - localMinMax[0];

        int minDistance = INT_MAX;

        for (int i = 1; i < n; i++) {

            minDistance = min(minDistance, localMinMax[i] - localMinMax[i-1]);

        }


        return {minDistance, maxDistance};

    }

};

优化：可以在遍历链表的过程中，记录第一个临界点的位置和记录前一个临界点的位置，来得到最大和最小临界点距离，将空间复杂度降为O(1)。

3. 合并零之间的节点#

简单题，遍历链表，时间复杂度为O(n)。


class Solution {

public:

    ListNode* mergeNodes(ListNode* head) {

        ListNode dummy;

        ListNode *newPrev = &dummy;

        auto cur = head;

        while (cur) {

            if (cur->val == 0) {

                    // 找到了值为0的节点

                cur = cur->next;

                // 如果该0节点为最后一个节点，直接退出循环

                if (cur == nullptr) break;

                // 统计两个0之间的元素之和，并创建新节点

                int sum = 0;

                while (cur && cur->val != 0) {

                    sum += cur->val;

                    cur = cur->next;

                }

                auto newNode = new ListNode(sum);

                newPrev->next = newNode;

                newPrev = newNode;

            }

        }


        return dummy.next;

    }

};

4. 分隔链表#

题目要求将一个链表划分为k部分，其中多余的部分均分到前面几部分中。


class Solution {

public:

    vector<ListNode*> splitListToParts(ListNode* head, int k) {

        // 1. 统计链表长度

        int n = 0;

        for (auto cur = head; cur; cur = cur->next) n++;


        // 2. 计算每段长度

        int base = n / k;

        int extra = n % k;


        // 3. 逐段切分

        vector<ListNode*> ans;

        auto first = head;

        for (int i = 0; i < k; i++) {

            ans.push_back(first);  // 记录当前段，空段为nullptr

            // 将多余的部分平均分给前extra段

            int len = base + (i < extra ? 1 : 0); 


            // 如果first已经为空，那么后面的for和if均不会进入

            auto last = first;

            for (int j = 0; j < len-1; j++) {

                last = last->next;

            }


            // 将链表断开

            if (last != nullptr) {

                auto nxt = last->next;

                last->next = nullptr;

                first = nxt;

            }

        }


        return ans;

    }

};

5. 链表组件#

组件的概念：所谓组件，就元素均在 nums 中出现过的最长连续子链表。

我的思路：

  • 使用哈希集合记录nums中的元素，快速判断元素是否存在于nums中

  • 然后遍历链表，确定条件的左侧，然后向后遍历找到右侧

  • 记录满足条件的组件数量

时间复杂度：O(n)，n 为链表长度

空间复杂度：O(m)，m为nums的长度


class Solution {

public:

    int numComponents(ListNode* head, vector<int>& nums) {

        unordered_set<int> st(nums.begin(), nums.end());

        auto left = head;


        int ans = 0;

        while (left) {

            while (left && !st.contains(left->val)) {

                left = left->next;

            }


            if (!left) break;


            auto right = left;

            while (right && st.contains(right->val)) {

                right = right->next;

            }

            ans++;

            left = right;

        }


        return ans;

    }

};

6. 移除链表元素#

我的思路：

  • 遍历链表，如果发现节点的值为val，就将其从链表中摘除

  • 单链表摘除节点必须获得其前驱，因此引入dummy节点统一操作

时间复杂度：O(n)，n 为链表长度。


class Solution {

public:

    ListNode* removeElements(ListNode* head, int val) {

        ListNode dummy(0, head);

        auto prev = &dummy;

        while (prev->next) {

            auto cur = prev->next;

            if (cur->val == val) {

                prev->next = cur->next;

            } else {

                prev = cur;

            }

        }

        return dummy.next;

    }

};

8. 删除排序链表中的重复元素#

题目给出了链表已经排序的假设，因此重复元素是连续的，所以我们只需要使用双指针法，左指针指向元素第一次出现的位置，右指针向后遍历链表直至其元素与左指针节点元素不同，更新左指针的后继为右指针，然后更新左指针，继续删除剩余的重复节点。

时间复杂度：O(n)，n 为链表长度。


class Solution {

public:

    ListNode* deleteDuplicates(ListNode* head) {

        // 链表已排序，重复元素连续

        if (!head || !head->next) return head;


        auto left = head;

        auto right = head->next;

        while (left) {

            while (right && right->val == left->val) {

                right = right->next;

            }

            left->next = right;

            left = right;

        }


        return head;

    }

};

9. 删除排序链表中的重复元素 II#

上题仅要求删除多余的重复元素，而本题则要求将所有存在重复的元素均删除。

思路与上题基本相似，不过需要通过left->next 是否等于 right来判断元素是否重复。

时间复杂度：O(n)，n 为链表长度


class Solution {

public:

    ListNode* deleteDuplicates(ListNode* head) {

        ListNode dummy(0, head);

        auto prev = &dummy;


        while (prev->next) {

            auto left = prev->next;

            auto right = left;

            while (right && right->val == left->val) {

                right = right->next;

            }


            if (left->next != right) {

                // 存在重复

                prev->next = right;

            } else {

                // 不存在重复

                prev = left;

            }

        }


        return dummy.next;

    }

};

10. 合并两个链表#

这道题目考查链表操作，本质上就是通过遍历找到三个节点，要删除的子链表的两个端点和list2的尾节点。

  • 前者直接遍历即可

  • 后者可以用快慢指针（连续两个指针）

  • 最后修改指针的指向，将链表重新连接即可


class Solution {

public:

    ListNode* mergeInBetween(ListNode* list1, int a, int b, ListNode* list2) {

        // 找三个指针，list1中节点a的前驱节点和节点b+1的前驱节点、list2的尾节点

        ListNode *p_l1 = list1, *q_l1 = list1;

        for (int i = 0; i < a-1; i++) p_l1 = p_l1->next;

        for (int j = 0; j < b; j++) q_l1 = q_l1->next;


        ListNode* last_l2 = list2;

        // 快慢指针找尾节点

        for (ListNode* fast = last_l2->next; fast; fast = fast->next) {

            last_l2 = last_l2->next;

        }


        p_l1->next = list2;

        last_l2->next = q_l1->next;

        return list1;

    }

};

11. 从链表中移除节点#

法一：暴力法

遍历链表，对于每个节点，遍历其右侧链表，查看是否存在比它大的节点，如果存在就将当前节点删除。

时间复杂度：O(n^2)，n为链表head的长度


class Solution {

public:

    ListNode* removeNodes(ListNode* head) {

        ListNode dummy(0, head);

        auto prev = &dummy;

        while (prev->next) {

            auto cur = prev->next;

            if (!cur->next) break;

                        // 遍历右侧链表，检查是否存在比当前节点值更大的节点

            auto right = cur->next;

            while (right && cur->val >= right->val) {

                right = right->next;

            }


            if (right != nullptr) {

                prev->next = cur->next;

            } else {

                prev = cur;

            }

        }


        return dummy.next;

    }

};

法二：翻转链表

💡

通过翻转链表，将判断右侧子链表是否存在更大的节点，转换为左侧节点是否存在更大的节点，避免重复遍历右侧链表。

先翻转链表，在遍历过程中记录遇到的最大值节点值，如果当前节点的值小于该最大值就将其删除，最后再次翻转该链表，得到结果。

时间复杂度：O(n)，n 为链表长度。


class Solution {

    ListNode* reverse(ListNode* head) {

        auto cur = head;

        head = nullptr;

        while (cur) {

            auto nxt = cur->next;

            cur->next = head;

            head = cur;

            cur = nxt;

        }

        return head;

    }

public:

    ListNode* removeNodes(ListNode* head) {

        head = reverse(head);


        ListNode dummy(0, head);

        int max_val = INT_MIN;

        auto prev = &dummy;

        while (prev->next) {

            auto cur = prev->next;

            if (cur->val < max_val) {

                prev->next = cur->next;

            } else {

                prev = cur;

                max_val = cur->val;

            }

        }

        dummy.next = reverse(dummy.next);

        return dummy.next;

    }

};

13. 在链表中插入最大公约数#

主要还是考察链表的遍历和指针操作的细节，每两个节点一组，求gcd并插入一个新节点。

时间复杂度：O(n)，n 为链表长度。


class Solution {

    int gcd(int a, int b) {

        if (a == 0) {

            return b;

        }

        return gcd(b % a, a);

    }

public:

    ListNode* insertGreatestCommonDivisors(ListNode* head) {

        if (!head || !head->next) return head;


        auto p = head, q = head->next;

        while (q != nullptr) {

            int result = gcd(p->val, q->val);

            auto newNode = new ListNode(result);

            p->next = newNode;

            newNode->next = q;


            p = q, 

            q = p->next;

        }


        return head;

    }

};

14. 对链表进行插入排序#

用一个dummy节点来存储排序后的列表，使用cur来遍历链表head，对于每个元素都从dummy→next开始向后搜索，直至找到第一个比他大的元素或prev→next为空时将cur插入。

时间复杂度：O(n²)，最坏情况下每个节点都要向已排序部分扫描；额外空间复杂度为 O(1)。


class Solution {

public:

    ListNode* insertionSortList(ListNode* head) {

        ListNode dummy;

        auto cur = head;

        auto prev = &dummy;

        while (cur) {

            while (prev->next && prev->next->val <= cur->val) {

                prev = prev->next;

            }

            auto nxt = cur->next;

            cur->next = prev->next;

            prev->next = cur;

            prev = &dummy;

            cur = nxt;

        }


        return dummy.next;

    }

};

15. 循环有序列表的插入#

链表head为非降序，使用双指针指向两个连续的节点，遍历链表，搜索插入点。


class Solution {

public:

    Node* insert(Node* head, int insertVal) {

        auto node = new Node(insertVal);


        // head为空链表

        if (!head) {

            node->next = node;

            return node;

        }


        // 搜索插入位置

        auto cur = head, nxt = head->next;

        while (nxt != head) {

            if (cur->val <= insertVal && insertVal <= nxt->val) {

                // insertVal在两个节点值之间，可插入

                break;

            }

            if (cur->val > nxt->val) {

                // insertVal可以放在末尾或首部

                if (insertVal > cur->val || insertVal < nxt->val) {

                    break;

                }

            }

            cur = cur->next;

            nxt = nxt->next;

        }

        cur->next = node;

        node->next = nxt;

        return head;

    }

};

17. 反转链表 II#

先找左端点的前驱和右端点，断开链接，通过reverse反转该子链表，最后重新建立链接。


class Solution {

    ListNode* reverse(ListNode* head) {

        auto cur = head;

        head = nullptr;


        while (cur) {

            auto nxt = cur->next;

            cur->next = head;

            head = cur;

            cur = nxt;

        }


        return head;

    }

public:

    ListNode* reverseBetween(ListNode* head, int left, int right) {

        ListNode dummy(0, head);

        auto l_prev = &dummy, r = &dummy;


        // 找到第left-1个节点 和 第right个节点

        for (int i = 0; i < left-1; i++) l_prev = l_prev->next;

        for (int i = 0; i < right; i++) r = r->next;

29. 环形链表 II#

要求找到环的入口。与其死记结论，不如理解相遇点的距离关系：设头节点到环入口距离为 a，入口到首次相遇点距离为 b，环长为 L。快慢指针相遇时，快指针比慢指针多走了整数圈，因此 2(a+b) = a+b+kL，得到 a+b=kL，即 a ≡ -b (mod L)。所以从头节点和相遇点同时出发、每次各走一步，两者会在环入口相遇。

            slow = slow->next;

            fast = fast->next->next;


            if (slow == fast) {

                slow = head;

                while (slow != fast) {

                    slow = slow->next;

                    fast = fast->next;

                }

                return slow;

            }

        }


        return nullptr;

    }

30. 环形数组是否存在循环#

给你一个数组 nums，每个位置 i 有一个值 nums[i]，表示从 i 出发要跳到哪个下标：

  • nums[i] > 0：向前跳 nums[i] 步（下标增大方向）

  • nums[i] < 0：向后跳 abs(nums[i]) 步（下标减小方向）

题目问的是：是否存在一个「循环」。循环的定义有三个条件：

  1. 能一直跳下去并回到某个已访问过的下标，形成环

  2. 环上所有 nums 必须同号（全正或全负），不能正负混着跳

  3. 环长 k > 1，也就是不能自己跳回自己（自环不算）

我的解题思路：

  • 外层：枚举每个起点 i，看从它出发能不能找到一个合法环。

  • 内层：从 i 出发，用龟兔赛跑判环，同时检查方向一致和自环。

  • 剪枝：但光这样最坏是 O(n²)，需要把已经确认「无环」的路径标记掉，下次不再走。

说明：该写法会把已处理位置改写为 0，因此会修改输入数组；若题目要求保留原数组，需要改用独立的访问状态数组。每个位置最多被标记一次，整体时间复杂度 O(n)，额外空间 O(1)。

class Solution {
    int nextIndex(const vector<int>& nums, int i) {
        int n = nums.size();
        // 先取模，再修正负数取模结果。
        return (i + nums[i] % n + n) % n;
    }

public:
    bool circularArrayLoop(vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return false;
        for (int i = 0; i < n; ++i) {
            if (nums[i] == 0) continue; // 0 作为已处理标记
            int dir = nums[i] > 0 ? 1 : -1;
            int slow = i, fast = i;

            while (true) {
                int nextSlow = nextIndex(nums, slow);
                if (nums[nextSlow] == 0 || (nums[nextSlow] > 0 ? 1 : -1) != dir)
                    break;
                if (nextSlow == slow) break; // 排除长度为 1 的自环
                slow = nextSlow;

                for (int step = 0; step < 2; ++step) {
                    int nextFast = nextIndex(nums, fast);
                    if (nums[nextFast] == 0 || (nums[nextFast] > 0 ? 1 : -1) != dir || nextFast == fast)
                        return markPath(nums, i, dir), false;
                    fast = nextFast;
                }
                if (slow == fast) return true;
            }
            markPath(nums, i, dir);
        }
        return false;
    }

private:
    int markPath(vector<int>& nums, int start, int dir) {
        int cur = start;
        while (nums[cur] != 0 && (nums[cur] > 0 ? 1 : -1) == dir) {
            int next = nextIndex(nums, cur);
            nums[cur] = 0;
            cur = next;
        }
        return 0;
    }
};

            slow = nums[slow];

            head = nums[head];

        }


        return slow;

    }

    }


    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {

        ListNode dummy;

        auto prev = &dummy;

        while (list1 && list2) {

            if (list1->val < list2->val) {

                prev->next = list1;

                list1 = list1->next;

            } else {

                prev->next = list2;

                list2 = list2->next;

            prev = prev->next;

41. 链表中的下一个更大节点#

法一：暴力法

遍历链表，对于每个节点，向后搜索下一个更大的节点，如果不存在就存储0，否则存储更大节点的值。

时间复杂度：O(n²)，额外空间复杂度为 O(1)。


class Solution {

public:

    vector<int> nextLargerNodes(ListNode* head) {

        // BF

        vector<int> ans;

        auto cur = head;

        while (cur) {

            int x = cur->val;

            auto r = cur->next;

            while (r && x >= r->val) {

                r = r->next;

            }


            ans.push_back(r ? r->val : 0);

            cur = cur->next;

        }

        return ans;

    }

};

法二：单调栈

在暴力法中我们反复遍历了链表的后续节点，浪费时间。

更直接的做法是先把链表值收集到数组，再从左向右使用单调递减栈（存下标）。当当前值大于栈顶下标对应的值时，当前值就是该位置右侧第一个更大值。每个下标最多入栈、出栈一次，因此总时间复杂度为 O(n)，空间复杂度为 O(n)。这种写法不会改变原链表。

思路：

  • 对于每个节点的值x，不断弹出栈顶直至栈为空或栈顶元素 > x

  • 如果此时单调栈为空，说明前面不存在大于x的元素，在ans中存入0

  • 否则，存入第一个大于该元素的值

时间复杂度：O(n)，空间复杂度：O(n)

class Solution {
public:
    vector<int> nextLargerNodes(ListNode* head) {
        vector<int> values;
        for (auto cur = head; cur; cur = cur->next)
            values.push_back(cur->val);

        vector<int> ans(values.size(), 0);
        stack<int> st; // 保存尚未找到下一个更大元素的位置
        for (int i = 0; i < (int)values.size(); ++i) {
            while (!st.empty() && values[st.top()] < values[i]) {
                ans[st.top()] = values[i];
                st.pop();
            }
            st.push(i);
        }
        return ans;
    }
};

44. LRU 缓存#

双向链表实现：

  • 哈希表加速根据key查找node的速度（缓存是否命中），时间复杂度为O(1)

  • 双向链表维护最近使用的关系，头部为最近使用的节点，尾部为最久未使用的节点

  • 如果当前节点数等于cap后还要继续加入缓存，则淘汰尾部的节点


class LRUCache {

    // 节点的定义：支持双向链接

    struct Node {

        int key_;

        int val_;

        Node *next_, *prev_;

    };


    // map：根据key快速获取节点

    unordered_map<int, Node*> lru_map;

    Node dummy;

    int cap_;


public:

    LRUCache(int capacity): cap_(capacity) {

        // 带dummy节点的双向循环链表

        dummy.next_ = &dummy;

        dummy.prev_ = &dummy;

    }

    int get(int key) {

        auto it = lru_map.find(key);

        int ans = -1;

        if (it != lru_map.end()) {

            // 缓存命中

            auto node = it->second;

            ans = node->val_;

            // 取出节点

            node->prev_->next_ = node->next_;

            node->next_->prev_ = node->prev_;

            // 头插

            node->next_ = dummy.next_;

            node->prev_ = &dummy;

            dummy.next_->prev_ = node;

            dummy.next_ = node;

        }

        return ans;

    }

    void put(int key, int value) {

        if (cap_ == 0) return; // 容量为 0 时不能淘汰哨兵节点

        auto it = lru_map.find(key);

        Node* node = nullptr;

        if (it != lru_map.end()) {

            // 找到key，更新内容

            node = it->second;

            node->val_ = value;


            // 取出节点

            node->prev_->next_ = node->next_;

            node->next_->prev_ = node->prev_;

        } else {

            if ((int)lru_map.size() == cap_) {

                // 淘汰最久未使用的尾部节点

                auto last = dummy.prev_;

                last->prev_->next_ = last->next_;

                last->next_->prev_ = last->prev_;

                lru_map.erase(last->key_);   // 同步从 map 移除

                delete last;

            }

            node = new Node;

            node->key_ = key;                // 记录 key

            node->val_ = value;

            lru_map[key] = node;             // 登记到 map

        }

        // 头插到链表

        node->next_ = dummy.next_;

        node->prev_ = &dummy;

        dummy.next_->prev_ = node;

        dummy.next_ = node;

    }

};

45. LFU 缓存#

LFU 可以理解为“按访问频率分层，每层内部再按最近使用时间排序”。 最低频率桶中的尾节点就是淘汰对象；访问一个节点时，将它从频率 f 的链表移到 f+1 的链表头部。

  • 统计每个节点在缓存中被访问的频数，初始为1

  • 每次访问都将在缓存中的节点频数+1

  • 淘汰策略：

    • 频率维度：淘汰频数最小的

    • 时间维度：频数相同时，淘汰最久未使用的（LRU）

数据结构的设计：

  • 节点的定义，包括双向链表的前驱指针和后继指针、key和value

  • 两个哈希表，一个用于根据key找对应节点，另一个用于根据频数找对应LRU链表的dummy节点

具体代码实现如下：


struct Node {

    int key;

    int value;

    int freq = 1; // 新书只读了一次

    Node* prev;

    Node* next;


    Node(int k = 0, int v = 0) : key(k), value(v) {}

};


class LFUCache {

private:

    int cap_;

    int min_freq_;

    unordered_map<int, Node*> key2node;

    unordered_map<int, Node*> freq2dummy;


    Node* get_node(int key) {

        auto it = key2node.find(key);

        if (it == key2node.end()) {

            return nullptr;

        }

        Node* node = it->second;

        remove(node);

        Node* dummy = freq2dummy[node->freq];

        if (dummy->prev == dummy) {

            freq2dummy.erase(node->freq);

            delete dummy;

            if (min_freq_ == node->freq) {

                min_freq_++;

            }

        }

        node->freq++;

        push_front(node->freq, node);

        return node;

    }


    Node* new_list() {

        Node* dummy = new Node();

        dummy->prev = dummy;

        dummy->next = dummy;

        return dummy;

    }


    void push_front(int freq, Node* x) {

        auto it = freq2dummy.find(freq);

        if (it == freq2dummy.end()) {

            // emplace 返回一个 pair<iterator, bool>：

            //  .first：指向插入元素的迭代器

            //  .second：bool，表示是否插入成功（true = 新插入）

            it = freq2dummy.emplace(freq, new_list()).first;

        }

        Node* dummy = it->second;

        x->prev = dummy;

        x->next = dummy->next;

        dummy->next = x;

        x->next->prev = x;

    }


    void remove(Node* x) {

        x->prev->next = x->next;

        x->next->prev = x->prev;

    }

public:

    LFUCache(int capacity): cap_(capacity) {}

    int get(int key) {

        Node* node = get_node(key);

        return node ? node->value : -1;

    }

    void put(int key, int value) {

        if (cap_ == 0) return;

        Node* node = get_node(key);

        if (node) { // 有这本书

            node->value = value; // 更新 value

            return;

        }

        if (key2node.size() == cap_) { // 书太多了

            Node* dummy = freq2dummy[min_freq_];

            Node* back_node = dummy->prev; // 最左边那摞书的最下面的书

            key2node.erase(back_node->key);

            remove(back_node); // 移除

            delete back_node; // 释放内存

            if (dummy->prev == dummy) { // 这摞书是空的

                freq2dummy.erase(min_freq_); // 移除空链表

                delete dummy; // 释放内存

            }

        }

        key2node[key] = node = new Node(key, value); // 新书

        push_front(1, node); // 放在「看过 1 次」的最上面

        min_freq_ = 1;

    }

};

47. 设计跳表#

表这种数据结构是由 William Pugh 发明的，关于跳表的详细介绍可以参考论文:「Skip Lists: A Probabilistic Alternative to Balanced Trees」，论文中详细阐述了关于 skiplist 查找元素、删除元素、插入元素的算法伪代码，以及时间复杂度的分析。跳表是一种随机化的数据结构，可以被看做二叉树的一个变种，它在性能上和红黑树、AVL 树不相上下，但是跳表的原理非常简单，目前在 Redis 和 LevelDB 中都有用到。

跳表的期望空间复杂度为 O(n)，跳表的查询，插入和删除操作的期望时间复杂度均为 O(logn)。

跳表实际为一种多层的有序链表，跳表的每一层都为一个有序链表，且满足每个位于第 i 层的节点有 p 的概率出现在第 i+1 层，其中 p 为常数。

跳表在进行查找时，首先从当前的最高层 L(n) 层开始查找，在当前层水平地逐个比较直至当前节点的下一个节点大于等于目标节点，然后移动至下一层进行查找，重复这个过程直至到达第一层。此时，若下一个节点是目标节点，则成功查找；反之，则元素不存在。由于从高层往低层开始查找，由于低层出现的元素可能不会出现在高层，因此跳表在进行查找的过程中会跳过一些元素，相比于有序链表的查询，跳表的查询速度会更快。

        head = prev->next;

        prev->next = nullptr;

        return head;

51. 扁平化多级双向链表#

dfs递归处理：

  • 使用dummy节点统一操作

  • 在dfs中

    • 如果当前节点为空直接返回

    • 否则，

      • 先将当前节点插入结果链表

      • 然后递归处理child

      • 根据题目要求，需要将child置为nullptr

      • 最后再处理同层的剩余节点

时间复杂度为 O(n)，递归栈空间复杂度为 O(d)，其中 d 为多级链表的最大嵌套深度；最坏为 O(n)。


/*

// Definition for a Node.

class Node {

public:

    int val;

    Node* prev;

    Node* next;

    Node* child;

};

*/

class Solution {   

    void dfs(Node*& prev, Node* cur) {   // prev定义为引用

        while (cur) {

            auto nxt = cur->next;


            prev->next = cur;

            cur->prev = prev;

            prev = cur;


            dfs(prev, cur->child);

            cur->child = nullptr;


            cur = nxt;

        }

    }

public:

    Node* flatten(Node* head) {

        if (!head) return head;


        Node dummy;

        dummy.next = nullptr;

        dummy.prev = nullptr;


        auto prev = &dummy;

        dfs(prev, head);


        auto newHead = dummy.next;

        newHead->prev = nullptr;

        prev->next = nullptr;

        return newHead;

    }

};

2. 写链表代码前的检查清单#

  1. 空链表：head == nullptr 时是否安全？
  2. 单节点：是否会访问 next->next 或错误地断链？
  3. 头节点变化：新头节点可能变化时，是否需要 dummy？
  4. 前驱关系：删除节点时是否持有其前驱？
  5. 保存后继：覆盖 cur->next 前，是否先保存 nxt = cur->next？
  6. 断链与重连：反转或分组后，旧尾节点是否重新连接到剩余链表？
  7. 终止条件：循环是否会遗漏最后一个节点，或在环形链表中无法终止？
  8. 副作用：题目是否允许修改原链表/原数组？
  9. 所有权：new 出来的节点由谁释放？是否可能误删 dummy？
  10. 复杂度：是否因为每个节点反复从头扫描而退化为 O(n²)？

3. 本笔记中值得特别记住的边界与实现细节#

  • 插入排序（14）：最坏时间复杂度是 O(n²)，额外空间 O(1)，不是 O(n)。
  • 最大公约数插入（13）：共有 O(n) 次节点处理，但每次 gcd 需要 O(log V) 时间，因此更严谨地写为 O(n log V)。
  • 环形数组（30）：必须同时检查方向一致、不能自环以及是否真正形成环。剪枝标记要保证每个位置只被处理常数次；上面的实现使用 0 标记已处理位置，因此会修改输入数组。
  • 下一个更大节点（41）：单调栈是线性解法。上面的实现先收集值再处理，不会像“先反转链表”的写法那样改变原链表结构。
  • 零和连续子链表（42）：哈希表应保存某个前缀和最后一次出现的位置。第二次遍历时，将当前节点的 next 直接连到该位置的后继，从而一次跳过中间和为 0 的区间。
  • LRU（44）：容量为 0 时必须直接处理，不能把 dummy 当作待淘汰节点删除。代码已加入 cap_ == 0 的保护。
  • LFU（45）：同样需要处理容量为 0。min_freq_ 表示当前缓存中最小的访问频率；访问节点时，若原频率桶变空且它恰好是最小频率，则最小频率递增。
  • MyLinkedList（43）与缓存（44、45）：题解为突出数据结构而使用裸指针。若脱离 LeetCode 单独使用，应补充析构函数，并明确禁止浅拷贝或实现拷贝/移动语义，否则可能发生内存泄漏或重复释放。
  • 跳表（47）：当前代码是学习用途的简化实现，不应直接视为 Redis 的完整实现。它使用裸指针和动态层数组，实际工程代码还需要明确重复 score 的排序规则、节点所有权、拷贝控制、随机数生成器以及异常安全。
  • 水塘抽样（50）：遍历到第 i 个节点时，以 1/i 的概率用当前节点替换答案。最终每个节点成为答案的概率均为 1/n。实际 C++ 项目中建议使用 <random> 的随机数引擎和均匀分布，而不是 rand() % i。
