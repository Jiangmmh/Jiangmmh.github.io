Getting Started#

Step one#

Hardware Description Language（硬件描述语言）使用代码来描述数字硬件。

下面是一个最简单的示例：

module top_module( output one );

    assign one = 1;

endmodule

该代码定义了一个名为top_module的module，没有输入，只有一个输出名为one，其中使用assign语句将输出端one置为1。

Zero#

同上，不过这里将输出端置为0。

module top_module(
    output zero
);// Module body starts after semicolon
	assign zero = 0;
endmodule

Verilog Language#

Basics#

Wire#

Create a module with one input and one output that behaves like a wire.

和物理的连线（wire）不同，verilog中的连线是有方向的。

我们可以使用assign语句连接输入和输出。

module top_module( input in, output out );
	assign out = in;
endmodule

Wire4#

Create a module with 3 inputs and 4 outputs that behaves like wires that makes these connections:

a -> w
b -> x
b -> y
c -> z


module top_module( 
    input a,b,c,
    output w,x,y,z );
	
    assign w = a;
    assign x = b;
    assign y = b;
    assign z = c;
    
endmodule

Notgate#

Create a module that implements a NOT gate.

注意：在verilog中，~表示按位取反，而!表示逻辑取反。

module top_module( input in, output out );

    assign out = ~in;
    
endmodule

Andgate#

Create a module that implements an AND gate.

module top_module( 
    input a, 
    input b, 
    output out );
	
    assign out = a & b;
    
endmodule

Norgate#

Create a module that implements a NOR gate.

module top_module( 
    input a, 
    input b, 
    output out );
	
    assign out = ~(a | b);
    
endmodule

Xnorgate#

Create a module that implements an XNOR gate.

在verilog中，使用 ^ 表示异或。

module top_module( 
    input a, 
    input b, 
    output out );

    assign out = ~(a ^ b);
    
endmodule

Wire decl#

随着电路越来越复杂，可能需要将一根wire连接到多处，这就需要为wire命名，而verilog提供了这个功能。

module top_module(
    input in,              // Declare an input wire named "in"
    output out             // Declare an output wire named "out"
);

    wire not_in;           // Declare a wire named "not_in"

    assign out = ~not_in;  // Assign a value to out (create a NOT gate).
    assign not_in = ~in;   // Assign a value to not_in (create another NOT gate).

endmodule   // End of module "top_module"

实现下面的电路。

module top_module(
    input a,
    input b,
    input c,
    input d,
    output out,
    output out_n   ); 
    
    wire ab, cd;
    assign ab = a & b;
    assign cd = c & d;
    assign out =  ab | cd;
    assign out_n = ~out;

endmodule

7458#

Create a module with the same functionality as the 7458 chip.

module top_module(
    input p1a, p1b, p1c, p1d, p1e, p1f,
    output p1y,
    input p2a, p2b, p2c, p2d,
    output p2y );
    
    wire w1, w2, w3, w4;
    assign w1 = p2a & p2b;
    assign w2 = p2c & p2d;
    assign w3 = p1a & p1c & p1b;
    assign w4 = p1f & p1e & p1d;
    assign p2y = w1 | w2;
    assign p1y = w3 | w4;

endmodule

Vectors#

Vector0#

Vector用于将信号聚合成组，使其容易被操作。其定义和使用的方法如下：

wire [99:0] my_vector;
assign out = my_vector[10];

Build a circuit that has one 3-bit input, then outputs the same vector, and also splits it into three separate 1-bit outputs.

module top_module(
    input wire [2:0] vec,
    output wire [2:0] outv,
    output wire o2,
    output wire o1,
    output wire o0  ); // Module body starts after module declaration
    
    assign outv = vec;
    assign o0 = vec[0];
    assign o1 = vec[1];
    assign o2 = vec[2];

endmodule

Vector1#

Vector的定义惯例如下：

type [upper:lower] vector_name;

其中的type指定了vector的数据类型，主要包括wire、reg和port（in和out）。

wire [7:0] w;         // 8-bit wire
reg  [4:1] x;         // 4-bit reg
output reg [0:0] y;   // 1-bit reg that is also an output port (this is still a vector)
input wire [3:-2] z;  // 6-bit wire input (negative ranges are allowed)
output [3:0] a;       // 4-bit output wire. Type is 'wire' unless specified otherwise.
wire [0:7] b;         // 8-bit wire where b[0] is the most-significant bit.

还可以自行定义使用常量Vector：

wire [2:0] a, c;   // Two vectors
assign a = 3'b101;  // a = 101
assign b = a;       // b =   1  implicitly-created wire
assign c = b;       // c = 001  <-- bug
my_module i1 (d,e); // d and e are implicitly one-bit wide if not declared.
                    // This could be a bug if the port was intended to be a vector.

Vector支持切片操作：

w[3:0]      // Only the lower 4 bits of w
x[1]        // The lowest bit of x
x[1:1]      // ...also the lowest bit of x
z[-1:-2]    // Two lowest bits of z
b[3:0]      // Illegal. Vector part-select must match the direction of the declaration.
b[0:3]      // The *upper* 4 bits of b.
assign w[3:0] = b[0:3];    // Assign upper 4 bits of b to lower 4 bits of w. w[3]=b[0], w[2]=b[1], etc.

Build a combinational circuit that splits an input half-word (16 bits, [15:0] ) into lower [7:0] and upper [15:8] bytes.

`default_nettype none     // Disable implicit nets. Reduces some types of bugs.
module top_module( 
    input wire [15:0] in,
    output wire [7:0] out_hi,
    output wire [7:0] out_lo );
    
    assign out_hi = in[15:8];
    assign out_lo = in[7:0];

endmodule

Vector2#

Build a circuit that will reverse the byte ordering of the 4-byte word.

AaaaaaaaBbbbbbbbCcccccccDddddddd => DdddddddCcccccccBbbbbbbbAaaaaaaa

module top_module( 
    input [31:0] in,
    output [31:0] out );

    assign out[7:0] = in[31:24];
    assign out[15:8] = in[23:16];
    assign out[23:16] = in[15:8];
    assign out[31:24] = in[7:0];
 
endmodule

Vectorgates#

Build a circuit that has two 3-bit inputs that computes the bitwise-OR of the two vectors, the logical-OR of the two vectors, and the inverse (NOT) of both vectors.

module top_module( 
    input [2:0] a,
    input [2:0] b,
    output [2:0] out_or_bitwise,
    output out_or_logical,
    output [5:0] out_not
);
    
    assign out_or_bitwise = a | b;
    assign out_or_logical = a || b;
    assign out_not[5:3] = ~b;
    assign out_not[2:0] = ~a;

endmodule

Gates4#

Build a combinational circuit with four inputs, in[3:0].

There are 3 outputs:

  • out_and: output of a 4-input AND gate.
  • out_or: output of a 4-input OR gate.
  • out_xor: output of a 4-input XOR gate.
module top_module( 
    input [3:0] in,
    output out_and,
    output out_or,
    output out_xor
);
    assign out_and = in[3] & in[2] & in[1] & in[0];
    assign out_or = in[3] | in[2] | in[1] | in[0];
    assign out_xor = in[3] ^ in[2] ^ in[1] ^ in[0];

endmodule

Vector3#

合并操作{a,b,c}用于将多个小的vector组合成一个大的Vector。

示例：

{3'b111, 3'b000} => 6'b111000
{1'b1, 1'b0, 3'b101} => 5'b10101
{4'ha, 4'd10} => 8'b10101010     // 4'ha and 4'd10 are both 4'b1010 in binary

这里有6个5-bit的输入端口，和4个8-bit的输出端口，根据下图所示的结构拼接输入，得到输出。

module top_module (
    input [4:0] a, b, c, d, e, f,
    output [7:0] w, x, y, z );//

    assign z = {e[0], f, 2'b11};
    assign y = {d[3:0], e[4:1]};
    assign x = {b[1:0], c, d[4]};
    assign w = {a, b[4:2]};

endmodule

Vectorr#

Given an 8-bit input vector [7:0], reverse its bit ordering.

module top_module( 
    input [7:0] in,
    output [7:0] out
);
    
    assign out = {in[0], in[1], in[2], in[3], in[4], in[5], in[6], in[7]};

endmodule

Vector4#

verilog还支持重复拼接的简写形式{num{vector}}：

{5{1'b1}}           // 5'b11111 (or 5'd31 or 5'h1f)
{2{a,b,c}}          // The same as {a,b,c,a,b,c}
{3'd5, {2{3'd6}}}   // 9'b101_110_110. It's a concatenation of 101 with
                    // the second vector, which is two copies of 3'b110

对输入in进行符号扩展得到输出out。

module top_module (
    input [7:0] in,
    output [31:0] out );

    assign out = {{24{in[7]}}, in};

endmodule

Vector5#

Given five 1-bit signals (a, b, c, d, and e), compute all 25 pairwise one-bit comparisons in the 25-bit output vector. The output should be 1 if the two bits being compared are equal.

out[24] = ~a ^ a;   // a == a, so out[24] is always 1.
out[23] = ~a ^ b;
out[22] = ~a ^ c;
...
out[ 1] = ~e ^ d;
out[ 0] = ~e ^ e;


module top_module (
    input a, b, c, d, e,
    output [24:0] out );//

    wire [4:0]t;
    assign t = {a, b, c, d, e};
    assign out = ~{{5{a}}, {5{b}}, {5{c}}, {5{d}}, {5{e}}} ^ {5{t}};

endmodule

Modules: Hierarchy#

Module#

module用于在verilog中的描述一个独立的电路，其有自己的输入和输出。我们可以将多个小的module组合成更大的module。

两种使用子module的方法：

  • 通过位置绑定输入：mod_a instance1 ( wa, wb, wc );
  • 通过名字绑定输入：mod_a instance2 ( .out(wc), .in1(wa), .in2(wb) );

假设我们现在已经有了一个module：

module mod_a ( input in1, input in2, output out );
    // Module body
endmodule

现在我们希望在top_module中使用它：

module top_module ( input a, input b, output out );
    mod_a instance1(a, b, out);
endmodule

Module pos#

如下图所示，使用mod_a实现top_module：

module mod_a ( output, output, input, input, input, input );

根据mod_a的输入和输出端口的位置，在top_module中使用它。

module top_module ( 
    input a, 
    input b, 
    input c,
    input d,
    output out1,
    output out2
);
    
    mod_a instance1(out1, out2, a, b, c, d);

endmodule

Module name#

这个练习用于让我们熟悉使用名字来连接子module的输入输出端。

module top_module ( 
    input a, 
    input b, 
    input c,
    input d,
    output out1,
    output out2
);
    
    mod_a instance1(.in1(a), .in2(b), .in3(c), .in4(d), .out1(out1), .out2(out2));

endmodule

Module shift#

题目提供了module my_dff：

module my_dff ( input clk, input d, output q );

实现如下图所示的电路：

module top_module ( input clk, input d, output q );
    wire t1, t2;
    
    my_dff instance1(clk, d, t1);
    my_dff instance2(clk, t1, t2);
    my_dff instance3(clk, t2, q);

endmodule

Module shift8#

题目提供了module my_dff8，构建类似上题的电路，并根据2-bits的sel信号选择输出：

module my_dff8 ( input clk, input [7:0] d, output [7:0] q );


module top_module ( 
    input clk, 
    input [7:0] d, 
    input [1:0] sel, 
    output reg [7:0] q 
);
    
    wire [7:0] t1, t2, t3;
    my_dff8 instance1(clk, d, t1);
    my_dff8 instance2(clk, t1, t2);
    my_dff8 instance3(clk, t2, t3);
    
    always @(*) begin
        case (sel)
            2'b00: q = d;
            2'b01: q = t1;
            2'b10: q = t2;
            2'b11: q = t3;
        endcase
    end

endmodule

这里通过alwasy case语句使用了行为建模（描述电路行为，而不是描述电路组件的连线），在always中不能使用assign语句，而是直接使用=或<= ，它们的区别后面会讲到。

使用module add16构造32位加法器：

module add16 ( input[15:0] a, input[15:0] b, input cin, output[15:0] sum, output cout );

    input [31:0] b,

    add16 instance1(a[15:0], b[15:0], 0, sum[15:0], cout_1);

Module fadd#

实现1-bit的full-adder：

module top_module (
    input [31:0] a,
    input [31:0] b,
    output [31:0] sum
);
    wire cout_1;
    add16 instance1(a[15:0], b[15:0], 0, sum[15:0], cout_1);
    add16 instance2(a[31:16], b[31:16], cout_1, sum[31:16]);
endmodule

module add1 ( input a, input b, input cin,   output sum, output cout );

// Full adder module here
    assign sum = a ^ b ^ cin;
    assign cout = (a & b) | (a & cin) | (b & cin);

endmodule

Module cseladd#

通过add16串联构成add32性能有限，因为计算高位数据的加法器要运行需要等待计算低位数据的加法器输出的cout。这里我们尝试对串联加法器进行优化。

module top_module(
    input [31:0] a,
    input [31:0] b,
    output [31:0] sum
);
    wire [15:0] out0, out1, sel;
    add16 instance1(a[15:0], b[15:0], 0, sum[15:0], sel);
    add16 instance2(a[31:16], b[31:16], 0, out0);
    add16 instance3(a[31:16], b[31:16], 1, out1);
	
    mux21_16 instance4(out0, out1, sel, sum[31:16]);
    
endmodule

module mux21_16 (
    input [15:0] a,
    input [15:0] b,
    input sel,
    output [15:0]out
);
    always @(*) begin
        if (sel) 
            out = b;
        else
            out = a;
    end
    
endmodule

Module addsub#

使用加法器硬件构造减法器：

module top_module(
    input [31:0] a,
    input [31:0] b,
    input sub,
    output [31:0] sum
);
    wire cout_1; 
    wire [31:0] sub_in, b_flip;
    
    assign sub_in = {{31{sub}}, sub};  // 符号扩展sub
    assign b_flip = b ^ sub_in;       
    
    add16 instance1(a[15:0], b_flip[15:0], sub, sum[15:0], cout_1);
    add16 instance2(a[31:16], b_flip[31:16], cout_1, sum[31:16]);
	
endmodule

Procedure#

Alwaysblock1#

verilog通过always语句提供了行为建模的电路构造方法：

  • Combinational：always @(*)
  • Clocked：always @(posedge clk)

组合逻辑的always块的敏感列表始终使用@(*) 或 @* ，

// 推荐：自动推导敏感信号
always @(*) begin
    y = a & b | c;
end

// 推荐：SystemVerilog
always_comb begin
    y = a & b | c;
end

// 不推荐：手动列出信号
always @(a or b or c) begin
    y = a & b | c;
end

wire和reg的区别：

  • wire：表示连线，用于连接模块，值由驱动源决定
  • reg：表示变量，用于过程赋值（always/initial 块）
// assign 语句左侧 → 必须是 wire（net 类型）
wire [7:0] q;
assign q = a & b;     // 正确

// always 块内赋值 → 必须是 reg（variable 类型）
reg [7:0] q;
always @(*) begin
    q = a & b;        // 正确
end

// synthesis verilog_input_version verilog_2001
module top_module(
    input a, 
    input b,
    output wire out_assign,
    output reg out_alwaysblock
);	
    
    assign out_assign = a & b;
    
    always @(*) begin
        out_alwaysblock = a & b;
    end
    

endmodule

Alwaysblock2#

对于存在时钟信号的电路，可以使用 **always @(posedge clk)**来定义。

三种赋值语句：

  • Continuous assignments (assign x = y;)。被用于always语句之外
  • Procedural blocking assignment: (x = y;)。被用于组合逻辑的always语句中
  • Procedural non-blocking assignment: (x <= y;)。被用于时序逻辑的always语句中

Build an XOR gate three ways, using an assign statement, a combinational always block, and a clocked always block. Note that the clocked always block produces a different circuit from the other two: There is a flip-flop so the output is delayed.

// synthesis verilog_input_version verilog_2001
module top_module(
    input clk,
    input a,
    input b,
    output wire out_assign,
    output reg out_always_comb,
    output reg out_always_ff   );
	   
		assign out_assign = a ^ b;
    always @(*) out_always_comb = a ^ b;
    always @(posedge clk) out_always_ff <= a ^ b;
endmodule

Always if#

verilog的always语句中支持if语句：

always @(*) begin
    if (condition) begin
        out = x;
    end
    else begin
        out = y;
    end
end

此外verilog还支持条件表达式：

assign out = (condition) ? x : y;

Build a 2-to-1 mux that chooses between a and b.

// synthesis verilog_input_version verilog_2001
module top_module(
    input a,
    input b,
    input sel_b1,
    input sel_b2,
    output wire out_assign,
    output reg out_always   ); 
    
    // 布尔代数的写法
    assign out_assign = (sel_b1 & sel_b2 & b) | ((~sel_b1 | ~sel_b2) & a);
    
    // 行为建模的写法
    always @(*)
        if (sel_b1 && sel_b2) begin
            out_always = b;
        end
    	else begin
            out_always = a;
        end
endmodule

Always if2#

  • 区分软件编程和硬件编程
    • Verilog语句正确不代表设计出来的电路就一定正确，
    • 记住：保持输出不变！！！
    • 软件编程像写菜谱：“如果饿了，就做饭”（不饿就不做，保持原状）。
    • 硬件设计像搭电路：“无论饿不饿，电路都必须输出一个明确的信号”（不能悬空或保持上次状态）。
    • 典型的错误：
      • if没有对应的else
      • case缺少default
    • 如果不考虑if为假的情况
      • 在 always @(*) 组合逻辑块中，如果某些条件下某个输出没有被赋值，综合工具会认为"这种情况输出保持不变"。
      • 问题：组合逻辑没有记忆功能，要"保持原值"就必须引入一个存储元件 → 锁存器（Latch）。

What you must not do is write the code first, then hope it generates a proper circuit.

  • If (cpu_overheated) then shut_off_computer = 1;
  • If (~arrived) then keep_driving = ~gas_tank_empty;
// synthesis verilog_input_version verilog_2001
module top_module (
    input      cpu_overheated,
    output reg shut_off_computer,
    input      arrived,
    input      gas_tank_empty,
    output reg keep_driving
);
		
    // 组合逻辑1：CPU过热时关机
    always @(*) begin
        if (cpu_overheated)
            shut_off_computer = 1;
        else
            shut_off_computer = 0;  // 明确赋值
    end
		
    // 组合逻辑2：未到达且油箱不为空时继续驾驶
    always @(*) begin
        if (~arrived)
            keep_driving = ~gas_tank_empty;
        else
            keep_driving = 0;  // 明确赋值（到达后停止驾驶）

该电路的输入是2字节的键盘扫描码，输出是根据扫描码中对应的按键输出left、down、right和up。

Scancode [15:0]	Arrow key
16'he06b	left arrow
16'he072	down arrow
16'he074	right arrow
16'he075	up arrow
Anything else	none

在组合逻辑中，当某些输出端口没有被明确赋值时，硬件需要锁存器来**保持（记住）**上次的值。

为什么要避免锁存器？

  1. 时序不确定：锁存器是电平敏感的，时序分析困难
  2. 可能产生毛刺：容易导致功能错误
  3. FPGA 资源浪费：大多数 FPGA 没有专用的锁存器单元，会消耗更多资源
  4. 设计意图模糊：通常是无意中产生的，不是设计者的本意

一种实现思路是在所有分支中进行赋值，但每个分支都要写 4 个赋值，代码冗余。

always @(*) begin
    case (scancode)
        8'h45: begin up = 1; down = 0; left = 0; right = 0; end
        8'h1D: begin up = 0; down = 1; left = 0; right = 0; end
        8'h1C: begin up = 0; down = 0; left = 1; right = 0; end
        8'h23: begin up = 0; down = 0; left = 0; right = 1; end
        default: begin up = 0; down = 0; left = 0; right = 0; end
    endcase
end

    output reg up  );

	    up = 1'b0; down = 1'b0; left = 1'b0; right = 1'b0;
	    case (scancode)
	        16'he06b: left = 1;
	        16'he072: down = 1;
	        16'he074: right = 1;

	    endcase
	    end

Adder100#

Create a 100-bit binary adder. The adder adds two 100-bit numbers and a carry-in to produce a 100-bit sum and carry out.

    input [99:0] a, b,
    input cin,

	assign {cout, sum} = a + b + cin;

为什么这样写是完美的？

  1. 自动位宽扩展：a 和 b 是 100 位，cin 是 1 位。当它们相加时，Verilog 会自动将 cin 扩展到 100 位进行计算。
  2. 拼接赋值：{cout, sum} 是一个 101位 的拼接向量（1位进位 + 100位结果），刚好能装下这 100 位数相加可能产生的最大结果（100位全1相加再加1，最多产生101位的结果），不会发生数据截断。
  3. 硬件优化：Vivado 等综合工具会将这行代码直接映射到 FPGA 内部的专用快速进位链（Carry Chain），不仅代码极简，而且生成的电路非常快，比你自己写 100 个全加器实例化要高效得多。

        input center;
        input right;

            case ({left, center, right})
                3'b111: rule110 = 1'b0;
                3'b110: rule110 = 1'b1;

Conwaylife#

**康威生命游戏（Conway’s Game of Life）**是一个在 16×16 环形网格 上实现的二维元胞自动机。

核心规则是每个细胞根据其8 个邻居（上、下、左、右、四个对角）的存活数量决定下一状态：

  • 0-1 存活的邻居: Cell 置为 0。
  • 2 存活的邻居: Cell 不变。
  • 3 存活的邻居: Cell 置为 1。
  • 4+ 存活的邻居: Cell 置为 0。

解释：

  • 邻居太少（<2）→ 孤独死
  • 邻居正好 2 个 → 保持原样
  • 邻居正好 3 个 → 新生（或保持存活）
  • 邻居太多（>3）→ 拥挤死

这个问题的难点不在于康威生命游戏的规则，而在于如何将长度为256的一维Vector转换为16*16的二维Vector。

module top_module(
    input clk,
    input load,
    input [255:0] data,
    output reg [255:0] q
);

    integer r, c;
    integer r_up, r_down, c_left, c_right;
    integer count;

    reg [255:0] next_q;

    always @(*) begin
        next_q = 256'b0;

        for (r = 0; r < 16; r = r + 1) begin
            for (c = 0; c < 16; c = c + 1) begin

          		// 获取当前cell的上下左右邻居的位置
                r_up   = (r == 0)  ? 15 : r - 1;
                r_down = (r == 15) ? 0  : r + 1;
                c_left = (c == 0)  ? 15 : c - 1;
                c_right= (c == 15) ? 0  : c + 1;
				
                // 获取全部存活的邻居数量
                count =
                    q[r_up*16   + c_left]  +
                    q[r_up*16   + c]        +
                    q[r_up*16   + c_right]  +
                    q[r*16      + c_left]  +
                    q[r*16      + c_right]  +
                    q[r_down*16 + c_left]  +
                    q[r_down*16 + c]        +
                    q[r_down*16 + c_right];

                if (count == 3)
                    next_q[r*16 + c] = 1'b1;
                else if (count == 2)
                    next_q[r*16 + c] = q[r*16 + c];
                else
                    next_q[r*16 + c] = 1'b0;
            end
        end
    end

    always @(posedge clk) begin
        if (load)
            q <= data;
        else
            q <= next_q;
    end

endmodule

Finite State Machine#

这部分我们将实现一些有限状态机。其设计思路如下：

  • 确定全部的状态集合
  • 画出状态转换图
  • 构造三个部分：
    • 一个组合逻辑的always，用于确定下一个状态 next_state
    • 一个时序逻辑的always，用于更新当前状态
    • 一条语句，用于根据当前状态产生输出结果

一个简单的FSM示例：

module top_module(
    input clk,
    input areset,    // Asynchronous reset to state B
    input in,
    output out);//  

    parameter A=0, B=1; 
    reg state, next_state;

    always @(*) begin    // This is a combinational always block
        // State transition logic
        case (state)
            A: next_state = in ? A : B;
            B: next_state = in ? B : A;
        endcase
    end

    always @(posedge clk, posedge areset) begin    // This is a sequential always block
        // State flip-flops with asynchronous reset
        state <=  areset ? B : next_state;
    end

    // Output logic
    assign out = (state == B);

    // 因此 data[8:1] 正好就是 d7...d0
    // =========================================================
    always @(posedge clk) begin
        if (reset)
            data <= 10'd0;
        else
            data <= {in, data[9:1]};
    end

    // =========================================================
    // Output
    // =========================================================
    assign done = (state == STOP);

    assign out_byte = data[8:1];

endmodule

module top_module(
    input clk,
    input in,
    input reset,
    output [7:0] out_byte,
    output done
);

    parameter IDLE       = 4'd0,
              START      = 4'd1,
              S1         = 4'd2,
              S2         = 4'd3,
              S3         = 4'd4,
              S4         = 4'd5,
              S5         = 4'd6,
              S6         = 4'd7,
              S7         = 4'd8,
              S8         = 4'd9,
              STOP_CHECK = 4'd10,
              STOP       = 4'd11,
              WAIT       = 4'd12;

    reg [3:0] state, next_state;

    reg [7:0] data;
    reg parity_ok;

    wire odd;

    // =====================================================
    // FSM
    // =====================================================
    always @(*) begin
        case (state)

            IDLE:
                next_state = in ? IDLE : START;

            START:
                next_state = S1;

            S1:
                next_state = S2;

            S2:
                next_state = S3;

            S3:
                next_state = S4;

            S4:
                next_state = S5;

            S5:
                next_state = S6;

            S6:
                next_state = S7;

            S7:
                next_state = S8;

            // S8 对应 parity bit
            S8:
                next_state = STOP_CHECK;

            // STOP_CHECK 对应 stop bit
            STOP_CHECK:
                next_state = in ? STOP : WAIT;

            // stop 正确
            STOP:
                next_state = in ? IDLE : START;

            // stop 错误，等待出现 1
            WAIT:
                next_state = in ? IDLE : WAIT;

            default:
                next_state = IDLE;

        endcase
    end

    // =====================================================
    // State register
    // =====================================================
    always @(posedge clk) begin
        if (reset)
            state <= IDLE;
        else
            state <= next_state;
    end

    // =====================================================
    // Data datapath
    //
    // START : d0
    // S1    : d1
    // S2    : d2
    // ...
    // S7    : d7
    // S8    : parity
    // =====================================================
    always @(posedge clk) begin
        if (reset) begin
            data <= 8'd0;
        end
        else begin
            case (state)
                START: data[0] <= in;
                S1:    data[1] <= in;
                S2:    data[2] <= in;
                S3:    data[3] <= in;
                S4:    data[4] <= in;
                S5:    data[5] <= in;
                S6:    data[6] <= in;
                S7:    data[7] <= in;
            endcase
        end
    end

    assign out_byte = data;

    // =====================================================
    // Odd parity checker
    //
    // 只统计：
    //
    // d0 d1 d2 d3 d4 d5 d6 d7 parity
    //
    // 不统计 start / stop / idle
    // =====================================================
    parity parity_check (
        .clk   (clk),
        .reset (reset ||
                (state == IDLE) ||
                (state == STOP) ||
                (state == WAIT)),
        .in    (in),
        .odd   (odd)
    );

    // =====================================================
    // 在 STOP_CHECK 时保存 parity 结果
    // =====================================================
    always @(posedge clk) begin
        if (reset)
            parity_ok <= 1'b0;
        else if (state == STOP_CHECK)
            parity_ok <= odd;
    end
		
    // =====================================================
    // done:
    //
    // 1. stop bit 正确 -> state == STOP
    // 2. 9 个 data/parity bits 是 odd parity -> parity_ok
    // =====================================================
    assign done = (state == STOP) && parity_ok;
		
endmodule
