1. CPU的基本组成和工作原理#

通过指令的组合实现需求, 就是编程。

  • CPU是一种通用的芯片，其提供了一组数量有限的指令集合；但CPU的用户可以按需求组合指令集中的指令，实现自定义的功能。

  • 指令分为操作码和操作数，前者指定处理数据的方式，后者指定要处理的数据。

  • CPU中提供一组通用寄存器存放临时值，指令需要操作数字段指出所使用的寄存器。

讲义笔记#

1. sISA和状态机#

计算机是一个机械地进行数据处理的设备，这里的“机械”是指其原理非常死板，毫无神秘可言。 计算机的ISA（指令集架构）定义了一组硬件规范（PC、GPR和内存）和一组有限的指令。

  • 在ISA之上，我们利用ISA提供的指令来构建操作系统、编译器等系统软件。

  • 在ISA之下，我们根据ISA的定义来设计数字电路，在物理上实现ISA的功能。

指令主要包括两部分内容：

  • 操作码：标识指令的功能

  • 操作数：标识指令要处理的数据

下面是一个简单的指令集架构——sISA所支持的指令：

下面是使用sISA指令实现的数列求和程序：


0: li r0, 10         # r0表示执行10次循环

1: li r1, 0          # r1表示循环变量i

2: li r2, 0          # r2表示和

3: li r3, 1          # r3表示i每次递增的步长

4: add r1, r1, r3

5: add r2, r2, r1

6: bner0 r1, 4

7: bner0 r3, 7

该程序的状态机模型如下：


PC r0 r1 r2 r3

(0, 0, 0, 0, 0)   # 初始状态

(1, 10, 0, 0, 0)  # 执行PC为0的指令后, r0更新为10, PC更新为下一条指令的位置

(2, 10, 0, 0, 0)  # 执行PC为1的指令后, r1更新为0, PC更新为下一条指令的位置

(3, 10, 0, 0, 0)  # 执行PC为2的指令后, r2更新为0, PC更新为下一条指令的位置

(4, 10, 0, 0, 1)  # 执行PC为3的指令后, r3更新为1, PC更新为下一条指令的位置

(5, 10, 1, 0, 1)  # 执行PC为4的指令后, r1更新为r1+r3, PC更新为下一条指令的位置

(6, 10, 1, 1, 1)  # 执行PC为5的指令后, r2更新为r2+r1, PC更新为下一条指令的位置

(4, 10, 1, 1, 1)  # 执行PC为6的指令后, 因r1不等于r0, 故PC更新为4

(5, 10, 2, 1, 1)  # 执行PC为4的指令后, r1更新为r1+r3, PC更新为下一条指令的位置

反复执行指令4, 5, 6，直至寄存器 r1 的值等于10时，继续向后执行指令 7。其中r0 存储数值10，寄存器 r1 用作计数器，求和的结果55会存储在寄存器 r2 中。

所谓编程, 实际上是利用给定功能（ISA中定义的指令）的组合来完成复杂任务的过程。

仿照前面的程序，重新设置循环上界和步长，构造出如下程序：


0: li r0, 11        &#x20;

1: li r1, 1

2: li r2, 0

3: li r3, 2

4: add r2, r2, r1

5: add r1, r1, r3

6: bner0 r1, 4

7: bner0 r3, 7

计算机自从诞生以来, 其工作过程就是一个数学游戏, 状态机模型只不过是这个数学游戏的规则。x86, ARM, RISC-V这些商业级别的真实ISA, 它们的GPR数量更多, 指令数量更多, 指令行为也更复杂。 但其本质原理和上述只有3条指令的sISA并没有本质区别, 因此, 如果你将来需要理解它们, 你只需要阅读相应的手册, 了解更多指令的细节即可

ISA除了指令的语义之外, ISA还包括输入输出, 系统状态, 中断异常, 虚存管理, 内存模型。随着学习进度的深入, 我们会依次向你介绍这些概念, 你也有机会将这些概念实现到自己设计的处理器中, 让处理器变得更强大。

C语言程序和机器指令程序可以理解为两个不同抽象层次下的状态机。这两个状态机的状态和状态转换函数不尽相同，但是它们所表达的内容是等价的。编译器的作用就在于将我们在较高抽象层次下构造的C程序状态机翻译为数字电路处理器能够直接执行的机器指令状态机。

关键思想：CPU设计 = 根据ISA设计数字电路

5. 从一到无穷大#

通过补码表示，计算机可以借助同一套加法器硬件来实现算术上的加法和减法。

  • 通过跳转指令实现循环，重复执行加法，可以实现乘法功能。

  • 重复执行减法，可以实现除法操作。

  • 通过整数的四则运算实现小数及其四则运算。

  • 然后进一步实现基本初等函数, 包括常函数, 幂函数, 指数函数, 对数函数, 三角函数, 反三角函数。

  • 实现了基本初等函数的计算后, 就可以通过基本初等函数之间的有限次有理运算和复合操作, 来计算所有初等函数了。

  • 对函数进行求导和积分根据导数的定义, 我们只需要代入一个很小的, 就能近似计算出函数在某一点的导数。

  • 将计算扩展到复数域其实也不难. 具体地, 我们只需要对实数分量和虚数分量分别进行计算, 另外再应用相关的规则处理虚数单位 i 即可。

  • 支持复数域的求导和积分后, 我们就可以在程序中实现各种物理引擎, 对真实世界中的各种物理规律进行模拟。

虽然上述功能都可以通过组织加减法指令和分支指令实现，但为了让计算过程更高效, 现代ISA还提供了更多的指令, 包括乘除指令, 逻辑运算指令(计算与, 或, 非等), 浮点指令, 原子指令等。

例如x86等CISC处理器期望通过提供功能更加强大的指令来提高程序性能，而RISC-V和MIPS等RISC处理器则保持克制，仅提供部分必要的指令，以保持指令格式的规整，通过流水线等技术加速程序执行的性能，而较为复杂的功能则如前面所介绍的那样，以软件的形式实现。
